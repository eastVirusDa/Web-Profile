소개

현재 특허 · 지식재산 도메인의 공공 시스템을 Java · Spring Boot 기반으로 개발하며, NHN KCP 결제 연동, Spring AOP 기반 로깅 및 커스텀 어노테이션 개발로 자동 추적 시스템 구현, 파일 입출력 기반 산출물 다운로드 등 서비스 핵심 기능을 구현해 왔습니다.
프로젝트에서는 성능과 안정성 문제를 직접 정의하고 해결해 왔습니다. 무신사 벤치마킹 프로젝트에서는 좋아요 기능의 Lost Update 문제를 원자적 쿼리로 해결해 데이터 정합성을 지키면서 응답 속도를 46% 개선했고, 주문 조회의 N+1 문제를 배치 쿼리로 풀어 DB 접근을 84% 절감했으며, 60,000건 이상의 상품 데이터 환경에서 커서 기반 페이지네이션을 구현했습니다. 복지팡이 RAG 에이전트에서는 LangGraph 기반 멀티 카테고리 상담 시스템과 다단계 폴백 검색을 설계하며 AI 서비스 개발까지 경험을 넓혔습니다. 비엔시스템 인턴십에서는 Spring AOP 활동 추적과 3단계 RBAC, Soft Delete 기반 이력 관리 등 운영 환경의 요구사항을 구현했습니다.
이 과정에서 SOLID 원칙과 디자인 패턴을 적용한 유지보수 가능한 설계, 정규화 기반의 데이터 모델링, 측정 가능한 성능 개선을 꾸준히 고민하며 코드를 작성해 왔습니다.
